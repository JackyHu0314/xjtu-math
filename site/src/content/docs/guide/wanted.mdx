## 缺的信息

1. **各班型的培养方案**：强基、试验班、大类每学期的必修和选修课。教务系统「培养方案」页面截图即可。
2. **公共课安排**：大学物理、程序设计、英语、思政等。
3. **分流规则**：时间、名额、依据。
4. **课程编号**：数学分析 I-1、I-2、II-2 等分别对应哪个学期、哪个班型。

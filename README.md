# 西交数学资料站

西安交通大学数学与统计学院的往年试卷、练习题、讲义和培养方案。

网站：https://xjtu-math-materials.pages.dev

## 投稿

- **不会用 git**：在 [Issues](../../issues/new/choose) 里选「资料投稿」，填表并把文件拖进去。维护者整理后会放到网站上。
- **会用 git**：直接提交 Pull Request，见 [CONTRIBUTING.md](CONTRIBUTING.md)。

上传前请涂掉姓名、学号。

## 目录

| 路径 | 内容 |
|---|---|
| `资料/课程/<课程>/试卷与习题、复习资料、讲义/` | 资料文件 |
| `资料/资料信息.csv` | 每份资料的标题、学期、班型、任课、作者、上传人等，网站据此显示 |
| `培养方案/专业课程.csv` | 三个专业的专业课表 |
| `site/` | 网站源码（Astro Starlight），说明见 [site/README.md](site/README.md) |
| `comments/` | 评论区后端（暂未启用） |
| `问卷设计.md` | 投稿问卷草稿 |

合并到 `main` 分支后，网站会自动重新发布。

## 声明

资料来自同学分享，仅供学习，不保证正确。正式出版的教材不在本仓库中，网站只列书名。资料作者如需删除，请提 Issue。

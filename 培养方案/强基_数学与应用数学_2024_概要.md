# 数学与应用数学（强基计划）培养方案概要（2024 版）

> 来源：自主选拔在线转载的西安交通大学本科招生网内容（https://www.zizzs.com/gk/qiangjijihua/157319.html，2024-04-19）。只有课程类别和代表课程，没有分学期的课表，还需要官方 PDF 补全。

- 学制 4 年，授予理学学士；满足条件可获得计算机科学与技术 / 软件工程辅修学位。
- 培养模式：“三制五化”（双院制、导师制、学分制；小班化、个性化、国际化、科教协同化、培养一体化），本硕博进阶式培养。

## 课程设置

| 类别 | 代表课程 |
|---|---|
| 通识教育：公共课程 | 思想政治理论、军事理论、大学英语、体育及劳育 |
| 通识教育：模块课程 | 通识类核心课程、通识类选修课程 |
| 大类平台：数学和基础科学 | 数学分析、高等代数与几何、大学物理、程序设计基础 |
| 大类平台：专业大类基础 | 常微分方程、抽象代数、离散数学、数据结构与算法、实变函数、复变函数、概率论、人工智能导论 |
| 专业必修 | 数值分析、运筹学、算法设计与分析 I、微分几何、多元数据分析与统计软件、机器学习 |
| 专业选修（数学与应用数学、信息与计算科学、人工智能、计算机与软件等模块） | 数学建模、随机过程、现代信息论、数理金融、自然语言处理、计算机视觉与模式识别、软件系统分析与设计、嵌入式智能系统 |
| 集中实践 | 军事训练、毕业设计、数据结构与算法设计综合训练、专业实习 |
| 课外实践 | 8 学分 |
